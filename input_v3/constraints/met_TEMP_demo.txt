# =====================================================================
# 【气象站序列样例】met_TEMP_demo.txt —— 气温逐时观测 → meteo.config 的 TEMP
# =====================================================================
# 用法: meteo.config 写  TEMP = file:constraints/met_TEMP_demo.txt
#       然后重建 runtime_v3.dat (cfgbuild 校验后在 SERIES 段登记)
#
# 物理作用: 温度直接进 Arrhenius 速率常数 (生成码里的 TEMP/300、EXP(-Ea/T)),
#           并经理想气体定律改空气数密度 M, 同时影响饱和水汽压 → H2O 浓度。
#           典型影响: 升温 5 K 使 O3 峰值上升数 ppb (见 run_M 的 OAT 结果)。
#
# ---- 格式说明 ----
#   t[s]  TEMP[K]     t = 自模拟起点秒; 必须严格递增; 只读前两列
#
# ---- 三条硬规则 ----
#   1) 不要写浓度单位指令行 (cm3/ppb/ppm 那套换算只属于浓度序列)。
#      气象量用原生单位; 写了 cfgbuild 会直接报错, 不会静默放大 2.46e10 倍。
#   2) 序列不循环。超出首/末时刻的仿真时间一律钳制到端点值,
#      所以想覆盖完整 5 天就写满 120 h (本文件 121 点 = 0..120 h)。
#   3) 点数 ≤ 128, 且与 BC 序列共享一个上限为 8 的序列池。
#      本套 6 个气象序列 + BC 序列, 总数不得超过 8。
#
# ---- 本样例的天气过程 ----
#   Day1-2 晴热 · Day3 08-14 时冷槽阵雨 (4 mm/h, BLH 压缩, 光解 0.45)
#   Day4 12-24 时云盖 (JFAC 0.55) · Day5 回晴
#   教学样例数据, 非真实观测; 换成你自己的站点观测请保持列格式
