## 1. P0 三项评估

### P0-1 光解槽位 m/n —— ✅ **已修（真错误，必须做）**

| 评估项 | 结论 |
|---|---|
| 是否影响正确性 | **是，严重**。J15 慢 28× → 丙酮几乎不光解，KET 虚高 |
| 实测影响 | GLY **+66%**、KET **−34%**、CH3CHO **+25%**、O₃ −1.9% |
| 横向对比 | CB6R3/MOZART 都用自己的光解表（Fast-J / 查表），**不存在"用近似形状替代官方值"的做法** |
| 结论 | **已在 V2.4 内完成**（不需等 V2.5） |

### P0-2 DMS → SO₂ 分支 —— ❌ **不必做（对本项目定位无影响）**

| 评估项 | 实测值 | 判读 |
|---|---|---|
| DMS 排放 | `1.0e4` molec/cm³/s | 仅 VOC 总排放的 **0.014%** |
| DMS 化学通量 | `7.8e8`（OH+NO₃） | vs `O₃+NO` 滴定 `1.24e13` → **0.006%** |
| SO₂ 排放 | `4.0e5` | DMS→SO₂ 若补上，最多贡献 `~7.5e3` = SO₂ 源的 **1.9%** |
| 对 O₃ 的影响 | 间接（SO₂ 不参与 O₃ 循环） | **≈0** |
| 横向对比 | **CB6R3 也没有完整 DMS 链**（只有 SO₂ 部分）；MOZART-4 有；RADM2 只有 SO₂ | 我们已与 CB6 持平 |
| 结论 | **跳过**。仅当你要做海洋硫化学专项（实验 E 的深度版）才需要 |

> 注：`mechanism/README` 里"海洋情景不可用"的表述应当修正为
> "海洋硫化学为简化版"——当前 DMS→MSA 直通已能给出量级正确的 MSA，
> 只是缺 SO₂ 中间分支。

### P0-3 N₂O₅ 非均相水解 —— ⚠ **条件性：无气溶胶面则不必做**

| 评估项 | 实测值 | 判读 |
|---|---|---|
| 夜间 N₂O₅ 占 NOy | **0.5%** | 极小 |
| 夜间 PAN 占 NOy | **57.5%** | 主导（高 VOC 环境特征） |
| 夜间 HNO₃ 占 NOy | 15.4% | 次之 |
| 横向对比 | CB6R3/MOZART/fullchem **都依赖气溶胶表面积**（γ·Sₐ） | 本机制 **0-D 无气溶胶** |
| 结论 | **不做**。加了 γ 但没有 Sₐ 数据 = 引入一个不可约束的自由参数，反而降低可解释性。若将来接气溶胶模块，再一并做 |

## 2. P1 四项评估

### P1-4 Criegee 显式化 —— 🔶 **建议做（唯一有实质物理收益的 P1 项）**

| 评估项 | 实测值 |
|---|---|
| Criegee 占**全天** OH 源 | **4.2%** |
| Criegee 占**夜间** OH 源 | **100%** ⚠ |
| 当前实现 | 产率法：`OLE+O₃→0.30 OH`、`ISOP+O₃→0.26 OH`、`TERP+O₃→0.80 OH` |
| 通量 | OLE+O₃ `5.8e10`、IOLE+O₃ `3.8e10`、ISOP+O₃ `2.3e9`、TERP+O₃ `4.9e8` |

**横向对比（关键）**：

| 机制 | Criegee 处理 |
|---|---|
| MCM v3.3.1 | **全显式**（本导出文件里 496 条 Criegee 相关反应，物种如 `CH2OO`/`CH3CHOO`/`MACROO`） |
| GEOS-Chem fullchem | 部分（主要 VOC 有，集总类用产率） |
| **CB6R3** | **无显式 Criegee**，用产率法 |
| **MOZART-4** | **无显式 Criegee**，用产率法 |
| RADM2 | 无 |
| **本机制** | 产率法（与 CB6/MOZART 同级） |

**判读**：如果目标是"对齐 CB6R3 / MOZART-4 复杂度"→ **不需要做**，我们已经是同级。
但实测发现**夜间 OH 100% 依赖 Criegee 产率法**，这意味着：
- 夜间化学（实验 C 的夜间版本、NO₃ 化学）的**所有定量结论都建立在 3 个产率参数上**
- 无法研究"Criegee 不同分解路径对 OH 的贡献"（科研价值项）
- 产率法无法给出 Criegee 自身的汇（水汽/NO/NO₂ 竞争），只能给净 OH

**结论**：**若你做夜间化学研究 → 做；若只做日间 O₃ 情景研判 → 不做。**
工作量 +4sp/+8rx（中等）。

### P1-5 RO₂ 交叉缔合全覆盖 —— ❌ **明确不必做（实测 0.34%）**

| 评估项 | 实测值 |
|---|---|
| RO₂+RO₂ 交叉通量合计 | `2.24e9` |
| RO₂+NO 通量合计 | `6.49e11` |
| **交叉占比** | **0.34%** |

**判读**：RO₂ 交叉在**高 NOx** 环境下几乎不发生（NO 抢占绝大多数 RO₂）。
只有当 NOx 极低（<100 ppt）时交叉才显著——而我们的城市情景 NOx 远高于此。
CB6R3 有交叉但同样低频；MCM 全谱有。

**结论**：**跳过**。现有 5 对已足够代表，扩到"按池权重自动生成"收益 <0.5%，
不值得框架改动。

### P1-6 异戊二烯第 4/5 分支 —— ❌ **不做（我们已领先 CB6/MOZART）**

| 评估项 | 实测值 / 对比 |
|---|---|
| ISOP 总通量 | `4.16e10`（OH 通道）；ISOPBO₂+NO `3.64e10` |
| 本机制异戊二烯链 | **7 物种**（ISOP, ISOPBO2, ISOPBO, ISOPNO3, ISOPNIT, ISOPDNT, ISOPOOH）+ MVK/MACR/MPAN 下游 |
| **CB6R3** | **集总 ISPD 单物种** |
| **MOZART-4** | **单物种** |
| RADM2 | 单物种 |
| MCM | 全显式（数百物种） |

**判读**：**我们的异戊二烯处理已经比 CB6R3 和 MOZART-4 细**。补第 4/5 分支
是向 MCM 靠拢，但会让我们比目标对比对象更复杂——方向不对。

**结论**：**跳过**。当前 7 物种二代链已足以支撑 FNR 判据与 ISOP 情景。

### P1-7 芳香烃二级产物（MUCO/EPOX） —— 🔶 **可做可不做**

| 评估项 | 实测值 |
|---|---|
| ARO1+OH 通量 | `1.46e11` |
| ARO2+OH 通量 | `1.71e11` |
| 现有下游 | CSL 甲酚开环 → GLY + MGLY → 二次 HCHO |
| **CB6R3** | TOL/XYL 官能团 + 环开裂产物（MUCO/EPOX 类） |
| MOZART-4 | 大类集总，无显式环开裂 |

**判读**：芳香烃是我们第二大 VOC 通量（3.2e11），当前用 CSL 单中间体代表开环。
与 CB6R3 相比缺 EPOX（环氧化物）和 MUCO（开环二羰基）两个分叉，会影响
**二次 HCHO 产率**的分配（当前全部经 GLY/MGLY）。

**结论**：**优先级低于 P1-4**。若做，收益是"二次 HCHO 来源更真实"，
工作量 +3sp/+5rx。建议与 P1-4 一起做，单独做收益不明确。

## 3. P2 三项评估（PAH 按你的要求排除）

### P2-8 有机酸（HCOOH / CH₃COOH） —— 🔶 **低优先**

| 评估项 | 说明 |
|---|---|
| 本机制现状 | 无这两个物种；HCHO+OH 全部走 HO2+CO |
| MCM 中通量 | MCM 有 32 条有机酸相关反应；HCOOH 由 HCHO+OH 的分支产生（约 15–20%） |
| **CB6R3** | 有 FORM/ACID（集总有机酸） |
| **MOZART-4** | 有 HCOOH/CH3COOH 显式 |
| 对 O₃ 的影响 | **≈0**（有机酸是终端产物，不参与 O₃ 循环） |
| 对 pH / 湿沉降 | 有影响，但本机制湿沉降是经验系数，无法体现 |
| 城市占比 | ~5% 的 VOC 质量，但 OH 反应性低 |

**结论**：**跳过**。它们对 O₃ 无影响，对湿沉降的影响本机制结构上无法体现
（无 pH / 无气溶胶）。若将来做酸沉降专项再补。

### P2-10 卤素碘化学（I / IO / HOI） —— ❌ **明确不做**

| 评估项 | 说明 |
|---|---|
| MCM v3.3.1 导出里 | **零个碘物种**（已实测 grep，无 I/IO/HOI/I2） |
| GEOS-Chem fullchem | 有（Sherwen 2016 统一卤素） |
| CB6R3 | **无**（r3m 变体只有 Cl/Br） |
| MOZART-4 | **无** |
| 适用场景 | 仅**海洋边界层** O₃ 损耗（碘的贡献约 1–3 ppb/day） |
| 本机制定位 | 城市/乡村/区域过程诊断 |

**结论**：**跳过**。连 MCM 官方导出都没有碘化学，我们做它既无参考基准、
也与本项目定位（城市 O₃ 过程诊断）不符。当前 Cl/Br 闭环已覆盖"卤素示范"的教学目的。

### P2-11 温度依赖的 RO₂ 交叉缔合 —— ❌ **不必做**

| 评估项 | 说明 |
|---|---|
| 前提 | RO₂ 交叉本身只占 **0.34%** 的 RO₂ 命运 |
| 现实现 | 统一 `KRO2NO3 = 2.3e-12` |
| 若加温度依赖 | 影响的是 0.34% 那部分的温度敏感性 → **净效应 <0.1%** |
| CB6R3 | 交叉速率有温度依赖，但同样低频 |

**结论**：**跳过**。给一个占比 0.34% 的通道加温度依赖，投入产出比极低。

### 结论：11 项里只有 1 项真正值得做

**推荐 V2.6 只做一件事：P1-4 Criegee 显式化（+ P1-7 芳香二级产物可选合并）。**

理由：
1. P0-1 已在 V2.4 内完成（它是真错误）
2. P0-2/P0-3 实测权重 ≈0，且受 0-D 结构限制（无气溶胶面）
3. P1-5/P1-6/P2-8/P2-10/P2-11 实测权重 <1% 或结构性不适用
4. **P1-4 是唯一"实测权重虽小但结构性重要"的项**——夜间 OH 完全依赖它
5. P1-7 与 P1-4 同属"二次产物分叉细化"，合并做边际成本低

| 指标 | 状态 |
|---|---|
| 无机化学 vs MCM | 最大偏差 **8.9%**（48 条） |
| 三大循环骨架 | 完整 |
| 复杂度 vs CB6R3 | 物种 135% / 反应 90% |
| 复杂度 vs MOZART-4 | 物种 131% / 反应 126% |

**这已经是一个自洽、可发表、可教学的状态。** V2.6 的 Criegee 升级是
"从够用走向可研究夜间自由基化学"的增量，不是修补缺陷。
