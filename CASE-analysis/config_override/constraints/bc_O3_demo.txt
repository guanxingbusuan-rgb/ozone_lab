# =====================================================================
# 【观测约束参考样例 ①】地面 O₃ 站点逐时观测 → bc.config 张弛约束
# =====================================================================
# 用途: bc.config 中写  O3 = file:constraints/bc_O3_demo.txt
#       模型会以 1/TAU_MIX 的速率被"拉向"这条曲线（Newtonian nudging）
#
# ⚠ 与 met_BLH.txt 的区别:
#   met_BLH.txt  → 气象（边界层高度），由 meteo.config 引用，是"物理环境"
#   bc_O3_demo.txt → 观测约束，由 bc.config 引用，是"真值校准"
#   两者格式相同（两列+单位头），但物理含义与登记位置完全不同
#
# ---- 格式说明 ----
#   # unit: ppb     单位指令（cm3 | ppb | ppm；缺省 cm3=molec/cm3）必写
#   # station: ...  站点标识（纯注释，供溯源）
#   t[s]  O3        t = 自模拟起点秒；必须严格递增
#
# ---- 硬约束（违反则 cfgbuild 编译期拒绝）----
#   • 点数 ≤ 128（本文件 24 点，正好一个日循环）
#   • 与气象等共享序列池，总序列数 ≤ 8
#   • 时间严格递增；缺测直接省行（自动线性插值 + 端点钳制）
#
# ---- 使用步骤 ----
#   1. 复制本文件为你自己的名字: cp bc_O3_demo.txt o3_station_MYSITE.txt
#   2. 替换为你的观测值（保持 t[s] 递增、单位一致）
#   3. bc.config 加一行:  O3 = file:constraints/o3_station_MYSITE.txt
#   4. make runtime_v3.dat   （cfgbuild 会校验）
#   5. cd facsimile_impl && ./fac_v3 SCEN_BAU ../output/assim ../runtime_v3.dat
#   6. 验证同化生效: 检查 <pref>_ipr.csv 中 O3_B 列显著非零
#
# ---- 建议 TAU_MIX（张弛强度）----
#   86400 s (~1天) = 弱，模型主导
#   21600 s (6h)   = 中，推荐起点
#    7200 s (2h)   = 强，观测主导（注意：过强会压制模型自身化学）
# =====================================================================
