# 用途: bc.config 中写  HCHO = file:constraints/bc_HCHO_demo.txt
#
# ⚠ HCHO 的特殊性（与 NO₂ 对比）:
#   • 机制内有真实局地化学（排放 5.8e4 + 光解 J₄ + OH 氧化），τ ~ 1–2 h
#   • 因此适合**中等 TAU_MIX**（21600 s），强约束会压制其光化学
#   • 是 FNR 指标的分子，卫星（TROPOMI）主产品
#   • 典型地面浓度 1–10 ppb（城市/生物源区）
#
# ---- 与 NO₂ 的 τ 选择对比 ----
#   HCHO: 21600 s（中等）—— 有局地化学，给模型留空间
#   NO₂ : 43200+ s（弱）—— 受光稳态支配，强 nudging 会破坏 PSS
#
# ---- 观测来源选项 ----
#   (a) 地面 HCHO 观测（DNPH-HPLC / PTR-MS）
#   (b) 卫星柱浓度经 inputproc/sat2surf.py 转表面等效 ppb:
#       python inputproc/sat2surf.py sat_HCHO.raw <程序>/config_override/constraints/bc_HCHO_demo.txt \
#              --blh-file <程序>/config_override/constraints/met_BLH.txt
#
# ---- 使用步骤 ----
#   bc.config 加行:  HCHO = file:constraints/bc_HCHO_demo.txt
#   重跑本程序 run.py，或手工: cd facsimile_impl && \
#     ./fac_v3 SCEN_BAU ../CASE-analysis/output/assim_hcho ../CASE-analysis/output/runtime_case.dat
#   验证: <pref>_ipr.csv 的 HCHO_B 列非零
