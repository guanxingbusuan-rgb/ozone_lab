# 用途: bc.config 中写  NO2 = file:constraints/bc_NO2_sat_demo.txt
#
# ⚠ NO₂ 的特殊性（最重要的坑）:
#   NO₂ 受 **NOx 光稳态（PSS）** 支配，τ ~ 分钟级。强 nudging 会把 NO₂
#   "钉死"在观测值上，破坏 Leith 循环（O₃+NO ⇌ NO₂+hν），导致
#       实测崩溃：h → 1e-79，O₃ 数值失真
#   → **正确做法：弱 τ（43200–86400 s）**，或走"自上而下排放反演"
#     （E_NOx ×= mean(obs)/mean(free)，见 experiments/obs_osse.py 通路③）
#
# ---- 数据来源: 卫星柱浓度转换 ----
#   S5P TROPOMI NO2_tropo 柱 → 表面等效 ppb（工具已内置两法互证 + QA 过滤）:
#     python inputproc/sat2surf.py configs/constraints/sat_NO2_x.raw \
#            configs/constraints/bc_NO2_sat_demo.txt \
#            --blh-file configs/constraints/met_BLH.txt
#   卫星每日一次过境 → 序列 86400 s 间隔（本样例为逐日值）
#
# ---- 柱量级参考（TROPOMI NO2 对流层柱）----
#   清洁背景  1e15–5e15 molec/cm2  →  地面 0.5–2 ppb
#   城郊      1e16–3e16            →  地面 4–12 ppb
#   城市污染  3e16–6e16            →  地面 12–25 ppb
#
# ---- 使用步骤（推荐弱 τ）----
#   TAU_MIX = 43200        # 12h，弱约束
#   NO2 = file:constraints/bc_NO2_sat_demo.txt
#   make runtime_v3.dat && cd facsimile_impl && \
#     ./fac_v3 SCEN_BAU ../output/assim_no2 ../runtime_v3.dat
